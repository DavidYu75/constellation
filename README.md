# Social Constellation 🌟
## Swift Student Challenge 2026 - App Playground

Transform your relationships into a living galaxy where each person becomes a star.

## 📱 About This Playground

This is a **Swift Playground App (.swiftpm)** designed for the Swift Student Challenge 2025. It runs directly in:
- **Swift Playgrounds 4.6+** on iPad
- **Swift Playgrounds** on Mac
- **Xcode 16+** (open the .swiftpm file)

## 🚀 Quick Start

### On iPad (Swift Playgrounds)
1. Transfer the `SocialConstellation.swiftpm` folder to your iPad
2. Open in Swift Playgrounds
3. Tap the "Run My Code" button

### On Mac (Xcode)
1. Double-click `SocialConstellation.swiftpm`
2. Xcode will open the playground
3. Press ⌘R to run

## 🎯 Features

- **Privacy First**: Demo mode available - no contacts required
- **Visual Galaxy**: Each contact becomes a star in your personal galaxy
- **Relationship Mapping**: Different colors for family, friends, colleagues
- **Time-Based Distance**: Stars drift away based on last contact
- **Interactive**: Tap stars to see details and reconnect

## 🎨 Customization

The playground includes demo data so it runs without contacts access. To customize:

1. **Adjust Star Colors** - Modify the `RelationshipType.color` computed property
2. **Change Animations** - Adjust duration and easing in `StarView`
3. **Add More Demo Stars** - Expand the `sampleNames` array in `loadDemoData()`

## 📦 Submission

To prepare for submission:
1. Ensure all code is in the .swiftpm folder
2. Test in Swift Playgrounds
3. Create ZIP: Right-click the `.swiftpm` folder → Compress
4. Verify ZIP is under 25 MB
